# Luv2-ShopApplication

Luv2-ShopApplication is an online fashion store application that I am building as a full-stack project using Java, Spring Boot and Angular.

I am developing the application step by step, starting with the backend and frontend structure and then connecting the different parts of the application together.

## About the Project

The goal of this project is to build a simple online shopping application where users can browse products, search for products, select product categories and eventually add products to a shopping cart and complete an order.

The project currently has the basic backend and frontend structure in place, and I am continuing to develop the functionality.

## Current Progress

So far, I have set up the Spring Boot backend with the basic project structure and created the Product and Product Category entities along with their repositories.

On the Angular side, I have created the main application structure and started building the components required for the online store.

The current Angular components include:

- Product Category Menu
- Product List
- Search

I have also created the Angular Product Service, which will be responsible for communicating with the Spring Boot backend.

Product images have been added to the Angular assets folder for categories such as books, coffee mugs, luggage tags and mousepads.

## Backend

The Spring Boot backend currently contains the basic structure for:

- Product
- Product Category
- Product Repository
- Product Category Repository
- REST configuration

The backend will be used to provide product and category information to the Angular application.

## Frontend

The Angular application currently contains:

- Product category menu
- Product list
- Product grid and table templates
- Search component
- Product service
- Product models
- Product images

I am currently working on connecting the frontend components with the backend APIs and adding the required functionality.

## Database

I have not created the MySQL database yet.

The project contains the starter SQL files that I will use when I set up the database. Once the database is created, I will connect it to the Spring Boot application and start retrieving the product information through the backend.
